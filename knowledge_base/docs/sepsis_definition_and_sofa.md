Sepsis is life-threatening organ dysfunction caused by a dysregulated host response to infection. In ICU prognosis work, the SOFA framework provides a practical way to track how respiratory, coagulation, liver, cardiovascular, neurologic, and renal systems are failing over time. Higher and persistent SOFA burden generally indicates a more severe physiologic trajectory. Prognostic reasoning should therefore explain not only that infection is present, but also which organ systems appear unstable in the current window.
